# DalamudCN Plugins

用于集中安装以下三个 DalamudCN 插件的在线仓库：

- `LiveFakeName`
- `Macro Shelf-A`
- `Nearby Player List`

## 在线安装

在 DalamudCN 设置的“自定义插件仓库”中添加：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
```

保存后即可在插件安装器中搜索并安装上述三个插件。

每个插件的安装包、图标和版本信息仍由各自仓库提供；这个仓库只维护统一的插件清单。
