- `LiveFakeName`
- [Macro Shelf-A](plugins/MacroShelfA/README.md)
- `Nearby Player List`
- `SkillMusicTrigger`
- `Auto Face`
- `Party Food Reminder`
- `DuanShuiJian`
- `Auto Gail`
- `FuckFurniture`
- `Slidecasting goat`
- [点数统计](plugins/DiceStats/README.md)
- [插件收纳盒（PluginShelf）](plugins/PluginShelf/README.md)
- [门铃迎宾（DoorbellCN）](plugins/DoorbellCN/README.md)
- `XivPing`
- [Pet Companion（宠物随行）](https://github.com/Alittlerecallinglittlebrother/PetCompanion)

## 在线安装

在 DalamudCN 设置的“自定义插件仓库”中添加：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
```

保存后即可在插件安装器中搜索并安装上述插件。

安装器会按仓库清单中的链接下载对应版本的安装包和图标。
