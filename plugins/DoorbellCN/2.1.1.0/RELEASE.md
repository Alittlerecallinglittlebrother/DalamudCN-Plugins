# 门铃迎宾 2.1.1.0 发布说明

## 发布内容

本版通过在线仓库的 `repo.json` 分发。安装包和源码包与已验证的本地 v2.1.1 交付包逐字节一致，仅改用英文文件名便于下载。没有改变任何其他插件条目或历史版本。

- 作者：**Aida Enna、断水剑**。
- 插件长简介、短简介均为：**6**。
- 取消宏结束后的 60–600 秒固定冷却、设置滑条和剩余冷却提示。
- 保留三秒合并、本场去重、宏占用保护、五分钟最多三次启动尝试及异常不重试。
- 旧配置及记录中的冷却字段不再使用；宏选择、访客标记、场次、启动次数和未决执行状态继续保留。

## 安装与升级

刷新现有在线库，在插件安装器中搜索“门铃迎宾”安装。先停用旧版本或本地开发版，不要同时加载两个版本；不要为了升级而删除去重文件。

宏迎宾默认不自动开启。先在住宅内用 `/echo` 宏确认功能正常，再选择实际迎宾宏。暂停或宏运行期间到访过的人，本场不再补发；需要重复测试时先让协助者离开，再开始新一场。新场次不能绕过五分钟次数上限。

安装包内的使用说明保留了本地构建路径示例；在线安装请以本仓库 README 为准。
