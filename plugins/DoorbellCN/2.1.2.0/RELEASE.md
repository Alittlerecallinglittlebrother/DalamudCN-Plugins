# 门铃迎宾 2.1.2.0 发布说明

## 本次修改

取消“五分钟最多三次”的迎宾宏启动限制，包括自动迎宾、手动测试、执行前检查、五分钟计数和恢复倒计时。不是仅隐藏界面或提高阈值。

- 第四批及更多新访客不再因次数被跳过。
- 本场次数只作统计，可以超过三次。
- 旧满额记录迁移后不再阻塞新访客。
- 删除旧启动时间表，内部记录格式升级为 3；访客标记、场次、累计尝试及未决宏状态保留。
- 旧版限流期间已登记的玩家仍属于本场已到访，不自动补发。
- 先前移除的宏结束后固定冷却不恢复。

继续保留固定三秒合并、本场去重、宏运行中不重复启动、约一秒空闲确认、先落盘后执行、异常不重试。原生游戏接口、宏指纹、访客检测和文件原子保存未改动。

作者仍为 **Aida Enna、断水剑**，长短简介均为 **6**。

## 更新

刷新在线库并更新到 2.1.2.0；本地开发版与在线版只启用一个，不删除配置或去重文件。重载后需要重新开启迎宾。

如果要重测同一玩家，让其先离开，再开始新一场；应使用本场未登记的人验证“第四位新访客”。取消上限后请自行控制宏内容和使用场合，避免频繁公开聊天。
