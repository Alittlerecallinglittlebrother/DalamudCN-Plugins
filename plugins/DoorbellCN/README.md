# 门铃迎宾（DoorbellCN）

当前在线版本 **2.1.2.0**，适配国服 Dalamud API 15。作者：**Aida Enna、断水剑**。插件管理器的长短简介均为 **6**。

## 在线安装与更新

在 DalamudCN 设置的“自定义插件仓库”中添加；已经添加过的用户只需刷新列表：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
```

搜索 **门铃迎宾** 安装或更新，使用 `/doorbellcn` 或 `/menling` 打开。

**先停用本地开发版和旧版，避免重复加载。** 不要删除原有配置和去重记录。更新不会自动开启宏迎宾；应先在住宅内使用仅含 `/echo` 的游戏宏测试，再手动启用。

## 本版规则

- **取消“五分钟最多三次”的限制**，自动迎宾和手动测试都不再按次数限流。
- 原来的宏结束后固定 60 秒冷却也不恢复。
- 保留固定 3 秒合并、本场去重、宏运行时不重复启动，以及约 1 秒空闲确认。
- 忙碌、暂停期间的访客仍会登记，不排队、不补发；本场次数只作统计。
- 升级前已满三次不影响新访客，但旧版已经登记的人不会自动补发。需要重新欢迎同一人时，让其先离屋，再开始新一场。
- 执行游戏中已有的个人宏或共通宏，不改写宏、不自动切换目标。
