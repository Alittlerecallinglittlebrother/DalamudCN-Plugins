# 门铃迎宾（DoorbellCN）

当前在线版本 **2.1.1.0**，适配国服 Dalamud API 15。作者：**Aida Enna、断水剑**。插件管理器的长短简介均为 **6**。

## 在线安装

在 DalamudCN 设置的“自定义插件仓库”中添加；已经添加过的用户只需刷新列表：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
```

搜索 **门铃迎宾** 安装，使用 `/doorbellcn` 或 `/menling` 打开。

**先停用本地开发版和旧版，避免重复加载。** 不要删除原有配置和去重记录。在线安装不会自动开启宏迎宾；应先在住宅内使用仅含 `/echo` 的游戏宏测试，再手动启用。

## 本版规则

- 执行游戏中已有的个人宏或共通宏，不改写宏、不自动切换目标。
- 取消宏结束后固定 60 秒冷却；约 1 秒空闲确认后，新访客可进入下一批。
- 保留固定 3 秒合并、本场去重、宏运行时不重复启动、最近五分钟最多三次启动尝试。
- 忙碌、暂停或限流期间的访客会登记，不排队、不补发；手动测试也计入次数。
- 升级保留访客和次数记录，旧冷却设置不再使用。
