# Macro Shelf-A 0.8.4.0

发布日期：2026-09-21。切职顺序修正版本，游戏内验收仍待完成。

## 本版内容

- 数字 `/gs change N`、`/gearset change N` 后，三处职业与目标套装一致才继续所有后续行，覆盖聊天、表情、中文动作、技能、独立 `/wait`、跨子宏及连续切装。
- 同职业不同套装也核对套装编号；有效目标的初始角色快照不可用时发送前中止。首次实际阻塞起 10 秒仍未同步就中止整段宏并提示。
- 被阻塞的行不提前消耗，显式等待从该行实际执行时开始。切装行自身的等待仍从切装命令发送时开始；普通宏额外行间隔为 0，每帧最多一行，不新增固定稳定延迟或重复动作。
- 主窗口与常用栏显示“等待职业与套装同步”，收起后仍能中止。
- 包含此前本地 0.8.3 系列的 ProcessChatBoxEntry 原生命令入口、实际加载版本查询和默认关闭的可选动作诊断。
- 配置版本 8、导出格式 4、原宏及原图图标保持兼容。

## 验证与已知边界

Release 构建 0 警告、0 错误；260/260 逻辑检查、98 项主窗口及 196 项常用栏断言通过。测试使用模拟游戏状态、离线原生入口回调和原生 ImGui 宿主。

上次有效复现记录到：切装后约 18 毫秒，`/divinearm` 已进入原生执行器并返回 True，但三处职业与套装仍是旧状态。旧 `/ac` 专用保护未覆盖表情；本次修正该公共调度缺口。

**职业及套装一致不证明动画、技能缓存或冷却已就绪；是否解决全部动作/技能失效仍待游戏内验收。** 套装名、相对编号、其他切装别名以及无法读取职业的目标不在本版目标解析范围，交由游戏处理。
