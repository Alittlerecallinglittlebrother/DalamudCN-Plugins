# Macro Shelf-A 0.9.4.0

发布日期：2026-09-27。作者：Akl。DalamudCN API 15 / .NET 10 / Windows x64。

插件简介：**当我受够了FF14那糟糕的宏指令**。

## 本次在线更新

本次将在线版从 0.8.4.0 更新至 0.9.4.0，包含此前仅本地交付的原生接入、三主题、编辑器与布局修正，以及本次确认的任务导航和清晰字体。

- **十个独立功能页**：我的宏、顺序宏组、常用宏悬浮栏、从游戏导入宏、生成游戏热键入口、图标与技能状态、倒计时结束后运行、插件宏备份与恢复、行数与等待设置、主题与悬浮入口。P3、主播女孩、P5 共用该操作逻辑，不再用“进阶 / 更多 / 简洁模式”隐藏功能。
- **保留主题风格**：三主题原有配色、品牌、装饰和动效不变；P3 人物仅作为左侧小装饰，窄窗口隐藏。经典界面的旧资料库 / 编辑台保留为兼容回退。
- **统一清晰字体**：功能文字使用原生常规字体与统一倍率，取消重复叠画加粗、人工斜体、按钮缩字及中文功能标题图片；品牌与装饰美术不受影响。
- **编辑与布局修正**：原生选区、语法文字和行号使用相同的字号 / 滚动原点；修正末行选择错位、列表与常用栏裁切、滚动条被背景遮挡、子面板越界。短窗导航可独立滚动，停止按钮保持可达。
- **真正接入各页面**：个人 / 共通宏预览与独立复制；普通玩家 PvE 技能图标、冷却与充能；按条目 ID 生成一行游戏宏入口。游戏宏槽位先备份再写入，覆盖与恢复保留明确确认。入口生成后仍由玩家手动拖到游戏热键栏。
- **执行与数据**：保留逐帧执行、完整显式等待、默认零额外间隔、数字切职后的顺序保护、宏组 / 子宏与倒计时机制。本次 0.9.4 界面改动不修改相对 0.9.3 的 Runtime 文件。相对在线 0.8.4，配置迁移至 9、交换格式为 5；旧宏 ID、正文、顺序和收藏保留，升级前生成配置备份。

## 安装与版本确认

已添加在线库的玩家刷新插件安装器后更新。首次安装请添加：

    https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
