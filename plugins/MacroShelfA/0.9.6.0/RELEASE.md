# Macro Shelf-A 0.9.6.0

国服客户端 `2026.10.06.0000.0000`（2026-10-13 更新），Dalamud API 15 / Windows x64 / .NET 10。

**离线编译与回归通过，但本版尚未完成游戏内功能验收。请保留配置备份，在安全场景复测；不匹配客户端仍会被保护机制拒绝。**

## 修改

- 重新核对客户端身份、ExecuteMacro / CancelMacro 地址和动作诊断入口，修复更新后原生路径被旧客户端档案拒绝的问题。
- 保留 SDK 布局、取消返回 ABI、宏归属与等待队列检查；没有删除保护、强行使用旧入口或静默回退。
- 沿用本地 0.9.5.3 的公告和界面，不改已有宏正文或游戏宏槽位。

## 升级注意

- 本包以本地公告版为基础。**新配置的原生执行默认关闭**；与之前线上 0.9.5.2 的默认开启行为不同。已有保存的开关值保持原样。需要原生执行时，在“行数与等待设置”手动开启；旧备份的缺省字段遵循本包实现，不继承旧线上版的缺省值。
- 只启用一个 Macro Shelf-A 实例，在线版和开发版不要同时启用，避免 `/aklmacro` 重复注册。
- 建议退出游戏后更新，再用 `/aklmacro version` 确认 0.9.6.0。
- 真正的技能/舞蹈动作、宏接管和取消仍需游戏内复测，不能把离线通过或 accepted/completed 日志当作动画验收。

## 验证

Debug / Release 编译通过；逻辑与原生 ABI 371/371 检查通过，原生 ImGui、快捷栏、导入、备份、设置及公告 UI 回归通过。版本包与本地已验证的安装包逐字节一致。

随版本提供 `MacroShelfA-source.zip`、`SHA256SUMS.txt`、`build-verification.json`。不含个人配置备份或游戏 EXE。
