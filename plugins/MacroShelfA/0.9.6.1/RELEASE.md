# Macro Shelf-A 0.9.6.1

## 本次更新

恢复原生宏执行默认开启，修正 0.9.6.0 基于本地分支发布时带入的默认值变化。生产代码相对 0.9.6.0 只修改配置默认值、备份缺省规则及版本号。

| 情况 | 行为 |
|---|---|
| 新配置、缺少 `UseNativeMacroExecution` 的旧配置 | 默认开启原生宏执行 |
| 配置明确保存 `true` 或 `false` | 保持已保存的选择 |
| v1–v4 旧备份替换导入 | 使用开启缺省值（这些格式不支持该字段） |
| v5 备份缺少字段 | 替换导入默认开启 |
| v5 备份明确保存关闭 | 替换导入保持关闭 |
| 追加导入 | 不改变当前执行、长宏或等待设置 |

已保存的关闭值，包括之前版本自动保存的关闭值，不会强制改成开启。如需使用原生模式，在“行数与等待设置”开启一次，或使用 `/aklmacro engine native`。

默认开启不意味着自动运行宏，不修改宏正文、ID、收藏、顺序或游戏宏槽位。

## 保持不变

- 国服客户端 `2026.10.06.0000.0000`、Dalamud CN API 15 / .NET 10 支持。
- 全部 Runtime 源文件、精确客户端档案、SDK 布局检查、CancelMacro ABI、归属和排空/取消保护。
- 分段、等待、原生执行、外部接管相关逻辑，未知客户端拒绝且不静默回退旧执行器。
- 主窗口公告、主题、原生执行开关文案和其他功能。

## 验证

- Debug / Release 构建通过，逻辑与原生 ABI **372/372** 检查通过。
- 原生 ImGui 离线交互回归：常规界面 113、快捷栏 199、导入 182、技能显示 76、热键桥接 25、任务导航 1798、原生设置 201、公告 681 条断言通过。
- 另在独立进程加载最终 Release `MacroShelfA.dll`，对实际程序集版本、默认构造、两种序列化器配置恢复、v1–v5 备份与导出回读验证 **53 条断言**。
- 公告回归覆盖默认开启和显式关闭两种设置，确认公告不改选择、不启动宏。测试宿主按 Framework 异步停止协议排空，未调用游戏原生函数。
- 安装包不携带 SDK、测试夹具或调试符号；源码包包含对应测试。

以上是离线验证；**本版本尚未完成游戏内宏动作、取消和外部接管验收**。此前较旧版本的游戏录像不能替代本版本验收。

## 安装

刷新原有订阅后更新到 0.9.6.1。建议完全退出游戏后更新；不要同时启用同名在线版和本地开发版。用 `/aklmacro version` 确认实际加载版本。

本次发布仅涉及 Macro Shelf-A，未发布或改动深海回响十六人版本。
