# Macro Shelf-A 0.9.6.10

适配国服 7.58 和卫月 API 15。

- 相邻的不同表情也可以按小数间隔交替执行，例如用 `<wait.0.4>` 切换左右动作。
- 独立的 `/wait` 与行尾等待会一起计入间隔。兼容 `/等待`、`<等待.0.4>`、英文大小写和 `<wait..4>` 等写法。

原生执行器的小数等待需开启「支持小数与长时间等待」。刷新卫月的自定义仓库后即可更新，用 `/aklmacro version` 查看加载的版本。

用本次发布的 DLL 实测了原生和旧版执行器，76 组宏的 394 条动作指令均按顺序执行。本轮输入间隔至少 0.05 秒的用例均采到逐行起播。极短间隔受游戏帧率影响，连续动作可能来不及看清。[验证记录](VERIFICATION.json)
