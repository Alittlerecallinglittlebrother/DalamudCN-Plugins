# Macro Shelf-A 0.9.6.16

卫月国服 API 15。已订阅在线库的玩家刷新插件安装器即可更新。输入 `/aklmacro version` 可查看实际加载的版本。

- 主界面、常用宏侧栏和游戏浮窗采用圆角布局。「外观与悬浮入口」支持简体中文、English、浅色、深色和跟随系统。
- 按住浮窗按钮可拖动并保存位置。点击「常用宏」可展开或收起侧栏，主界面有独立的打开按钮。
- 备份可另存为 JSON 文件，也可选择文件后追加宏或确认替换宏库。
- 删除宏与替换宏库的确认框会随窗口调整。正文可单独滚动，操作按钮保持可见。公告、备份文件选择窗和常用宏选择器也已适配窄窗与大字号。

从旧版升级时，插件会先备份含顺序宏组的配置，再把组内宏按原顺序迁为独立宏。原来绑定整个宏组的游戏热键或倒计时需要重新选择目标。
