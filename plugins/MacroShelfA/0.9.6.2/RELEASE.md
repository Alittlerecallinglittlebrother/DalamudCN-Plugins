# Macro Shelf-A 0.9.6.2 发布说明

## 发布基线与范围

基于 GitHub 仓库 `Alittlerecallinglittlebrother/DalamudCN-Plugins` 上一在线版 0.9.6.1 的公开源码包制作，原包 SHA256：
`1FB816C23955471F6626F75DB4893BFE3711A46ECA76E5BBC3782BF531654E17`。

通过在线仓库的 repo.json 分发本版，保留所有历史版本和其他插件条目。此次发布不会自动安装到本机卫月，也不修改用户配置或游戏文件。

## 功能与修复

1. **公告可读**：删除“固定白字 + 继承浅色背景”的组合，整套弹窗颜色跟随主题。正文、标题、按钮默认/悬停/按下颜色均有离线对比度断言。
2. **公告不重复打扰**：新属性 `AcknowledgedAnnouncementVersion` 保存内容版本。首次升级确认后，关窗重开、插件重载、主题/字号切换都不再重复提示。公告两个按钮与标题栏 × 都算确认；临时隐藏或关闭整个主窗不算。
3. **手动查看**：“主题与悬浮入口”（经典界面为“设置”）中的“查看公告”。
4. **自定义字号**：`UiFontScale` 默认 1，范围 0.8–1.5；滑块和 Ctrl+点击输入，结束调整后自动保存，可恢复默认。覆盖插件各窗口、编辑器、公告、常用栏。主题贴图/品牌装饰不随文字字号重新生成。
5. **字体安全**：使用 Dalamud 托管的默认字体构建接口，不修改 FontGlobalScale 或共享字体。作用域覆盖整个插件窗口系统，新字体准备好才替换旧字体，异常也释放字体栈。默认 100% 不创建自定义字体。

字号和已读状态是本机显示偏好，不进入宏交换格式；追加/替换宏备份都保留。配置版本仍为 9（新增可选字段，无破坏性迁移）。

## 验证与限制

- Debug / Release 构建均为 0 警告、0 错误；376 项逻辑/ABI 测试、4829 条 UI 断言通过（其中公告 1385、字号 850）。安装包 DLL 与此 Release 构建逐字节一致。详见同目录 VERIFICATION.json 和 SHA256SUMS.txt。
- 公告：四主题、原生执行默认开启/显式关闭、重复打开、保存重载、手动查看、×、隐藏恢复、其他模态框和卸载。
- 字号：四主题 × 80/100/125/150% × 全局 100/150%；滑块、直接输入、重置、保存重载、输入框/中文插入/撤销/光标行高、常用栏、720×500 公告可关闭。
- 测试宿主使用真实 ImGui 绘制，不是网页重建截图。字号测试模拟 Dalamud 字体句柄的准备时序，字体本身由原生 ImGui 分尺寸栅格化。已修正测试软渲染器对多页中文字体图集的处理。
- 保留所有 Runtime 源文件；不改变宏执行器、原生校验、等待/取消协议或宏文本。
- **未做本版本游戏内实测。** 离线测试不证明真实游戏中的 Dalamud 字体异步构建/中文字体回退或宏动作均通过。

## 游戏内建议验收

1. 备份配置，只启用一个在线版或本地开发版，确认版本为 0.9.6.2。
2. 主播女孩主题下检查公告正文、标题、两个按钮，确认后关闭/重开并重载插件，公告不再自动弹出。
3. 手动“查看公告”后分别使用 × 和“前往设置”，检查关闭与跳转。
4. 字号调至 125%、150% 及恢复默认；检查中文编辑、光标、悬浮栏，再重载验证保存。
5. 游戏及其他插件字号保持不变；字体构建若失败会保留旧字体/默认字体，不应修改宏或启停执行器。

维护提示：只有真正变更公告内容时才增加 `MainWindow.CurrentAnnouncementVersion`，不要随普通插件升级递增。
