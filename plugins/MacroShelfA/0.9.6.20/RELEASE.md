# Macro Shelf-A 0.9.6.20

卫月国服 API 15。已订阅在线库的玩家可刷新插件安装器后更新。输入 `/aklmacro version` 可查看实际加载的版本。

## 播放器同步

1. 在桌面播放器中开启 Windows 系统媒体传输控件（SMTC）。
   - **网易云音乐**。右上角「设置」→「系统」，勾选「开启SMTC」。
   - **QQ 音乐**。左下角齿轮「主菜单」→「设置」→「常规设置」→「通知」，勾选「显示系统媒体传输控件（SMTC）」。
2. 在播放器里选歌，播放后暂停到想开场的位置。
3. 在 Macro Shelf-A 选中要运行的宏，点「播放器同步」。选对应播放器，确认歌名和宏名后点「开始同步」。

Windows 确认歌曲开始播放后，插件会运行选中的宏。同步面板内的「使用教程」随时可展开。「更多设置」可调整同步延迟，延迟期间可点「取消同步」。
