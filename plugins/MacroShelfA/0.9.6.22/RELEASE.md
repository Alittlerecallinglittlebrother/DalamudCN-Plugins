# Macro Shelf-A 0.9.6.22

卫月国服 API 15。刷新插件安装器后更新 Macro Shelf-A。输入 `/aklmacro version` 可以确认加载版本。

## 用酷狗音乐同步宏

1. 在酷狗电脑版点击右上角三横线，打开「设置」→「常规设置」→「播放」，勾选「支持系统播放控件，如锁屏界面」。
2. 在酷狗选好歌曲，播放后暂停到想开场的位置。
3. 回到 Macro Shelf-A 选中要运行的宏，打开「播放器同步」并选择「酷狗音乐」。确认歌名和宏名后点击「开始同步」。

面板内的「使用教程」中也能查看设置步骤。
