# Macro Shelf-A 0.9.6.26

适用于卫月国服 API 15。刷新插件安装器后更新 Macro Shelf-A，可用 `/aklmacro version` 确认加载版本。

## 在宏里使用背包道具

1. 在「我的宏」选中一个宏，点右侧「宏命令」标题下的「插入道具」。
2. 按道具名称、类别或 ID 搜索。同名道具可以按 ID 选择。要使用高品质道具，勾选「高品质 (HQ)」。
3. 点选一项会把指令追加到当前宏末尾。可把它移到需要的时间点，和 `/wait`、表情等指令一起运行。

| 用法 | 示例 |
| --- | --- |
| 按名称使用普通品质道具 | `/aklmacro item 苍穹烟花` |
| 按名称使用高品质道具 | `/aklmacro item --hq 恢复药` |
| 按 ID 选择道具 | `/aklmacro item #12042` |

道具使用遵循游戏的背包、冷却和场景限制。此版本修复了道具已经生效却出现无法使用提示的问题。

## 在宏里佩戴时尚配饰

搜索配饰名称，选择标有「时尚配饰」的结果，即可插入游戏原生指令。也可以直接写入 `/时尚配饰 大天使之翼`。标有「解锁道具」的结果对应一次性背包物品，用于解锁配饰。
