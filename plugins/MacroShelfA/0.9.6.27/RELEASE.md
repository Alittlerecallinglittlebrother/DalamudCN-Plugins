# Macro Shelf-A 0.9.6.27

适用于卫月国服 API 15。刷新插件安装器后更新 Macro Shelf-A，可用 `/aklmacro version` 确认版本。

## 时间轴执行

1. 将舞序导出的宏导入 Shelf-A，在「我的宏」选中对应条目。
2. 在宏编辑区勾选「时间轴执行」，点击「运行此宏」。可用「停止运行」或 `/aklmacro stop` 中止。

Shelf-A 按同一个起点安排每条指令，支持独立 `/wait`、行尾小数等待和连续短间隔。舞序负责编辑和导出，Shelf-A 独立执行时间轴。

超过 15 行的宏需要在「执行与等待」开启「允许超过 15 行」。某条指令超过计划时点 200 毫秒时，插件会提示对应行号并中止。使用 `/mlock` 一类依赖游戏原生宏状态的指令时请选择原生宏执行。

## 备份与恢复

- 替换导入会恢复备份中明确提供的受支持设置。纯宏包省略的设置沿用本机值，追加导入沿用本机执行设置。
- 修复在「选择 JSON 文件」窗口点击文件时触发的异常。
