# Macro Shelf-A 0.9.6.8

适配国服 7.58 和卫月 API 15。

- 连续写同一个表情时，可按小数间隔逐行重播，支持同一表情的中英文指令和简称。
- 修复同一游戏进程内重载插件后，短间隔表情重播失效的问题。
- 编辑器提示改为「等待支持 3 位小数· 自动保存」。等待设置示例为 `/wait 0.125`、`/wait 120`、`<wait.0.125>`。

原生宏的小数等待需开启「支持小数与长时间等待」。在卫月插件安装器刷新自定义仓库后更新，可用 `/aklmacro version` 查看实际加载版本。

国服 7.58 实测两次热重载后，连续四行 `/cheer<wait.0.3>` 均逐行起播。发布构建的提示文案通过离线界面检查。[验证记录](VERIFICATION.json)
