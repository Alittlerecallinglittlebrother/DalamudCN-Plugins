## 本次更新：默认行间隔为 0

- 直接去除原来的 0.15 秒默认行间隔，不需要任何开关。
- 无显式等待的命令下一帧继续，每帧最多一行；并非同一帧批量发送全部命令。
- `/wait`、`<wait.N>`、小数等待、子宏末行及整组最终等待完整保留，从命令实际派发时刻计时。
- 独立宏、单独子宏、整组和倒计时启动均采用同一规则。
- 不包含本地试验版的统一时间轴、音乐卡点、迟到 0.5 秒中止及“执行计时”页；不会因为旧配置中的计时选项而重新启用。
- 卡顿恢复后仍按顺序逐帧执行，不集中补发，显式等待不被压缩；帧误差仍可能累计。

零间隔指插件没有额外添加固定等待；实际命令间距仍受帧率与游戏处理影响，未验证与原生宏所有时序行为完全一致，也不提供音乐同步。

## 宏组与子宏

在“编辑宏”中创建宏组，总按钮及子宏名称均可自定义。点击总按钮按顺序运行全部子宏，也可单独运行某个子宏。支持排序、复制、删除和添加已有独立宏的副本。自动衔接，无需 `/nextmacro`，不占用游戏宏槽位。

每组最多 64 个子宏；全局最多 200 个条目（含组、子宏与独立宏）。

## 解除 15 行限制

勾选窗口上方的 **解除 15 行限制**，独立宏和子宏即可超过 15 行，每宏最多 64,000 字符。此开关默认关闭，升级保留原设置，关闭不会截断文本；运行中更改只影响下次启动。

支持 `/wait 3`、`/wait 0.5`、`<wait.3>` 和 `<wait.0.5>`。游戏内动作是否成功仍由游戏决定。

## 小队战斗倒计时触发

1. 打开 **事件触发** 页签。
2. 在 **执行目标** 中选择独立宏或宏组。
3. 勾选 **战斗倒计时结束后执行宏**（默认关闭）。
4. 自己或队友发起下一轮完整小队倒计时，正常结束时自动执行一次。

监听真实倒计时状态，并由游戏专用“战斗开始”事件确认；普通聊天、喊话或 `/echo 战斗开始！` 不触发。取消、登出、切图、无效状态不触发；已有宏执行时跳过，不打断、不排队。启用、重载或更换目标时已在进行的倒计时不触发，从下一轮完整倒计时生效。

目标使用固定 ID，重命名与排序不影响绑定；删除目标或替换导入会关闭。追加导入保留本机绑定，导出不携带自动触发绑定。关闭监听不停止已经启动的宏，停止请使用顶部“中止整组”。

## 配置兼容

配置模型 **8**，导出格式仍为 **4**，支持导入格式 1–4。保留宏内容、宏组顺序、长宏、等待、悬浮入口与有效倒计时绑定；旧的 `UseTimelineScheduling`、`RemoveDefaultInterval` 字段会被忽略，保存和导出不再写出。

升级前新增一次性 `config-before-zero-interval-v8.json`，不覆盖已有备份，原 v4/v5/v6 备份逻辑保留。该备份由当前配置模型序列化，不包含已删除的两个计时字段。替换导入应用等待和长宏设置，同时停止执行并清除倒计时绑定。

## 验证范围

Release 构建 0 警告、0 错误；**112/112 逻辑测试通过**。117 行等待分布在 144、60、30、15、10 Hz 模拟下完整执行，单宏与拆分 8 子宏的发送时刻一致，显式等待未缩短。

原生 ImGui 宿主通过宏组、400 行中文编辑、长宏开关、倒计时绑定、导入与停止交互回归，并检查 720×500、940×760、1200×900 和 1.5 倍布局缩放。游戏命令、倒计时采样、日志事件及内存补丁边界使用测试桩，**尚未游戏内实测**。
