# Macro Shelf-A

当前在线版本：**0.8.2.0**。作者：**Akl**。DalamudCN API 15 / .NET 10。

插件简介：**当我受够了FF14那糟糕的宏指令**。

## 已知问题与发布范围

**用户反馈：切换占星后，聊天与“即刻咏唱”可执行，但后续“阳星合相”未执行，四行宏无提示结束。该问题仍在排查，尚未确认修复。**

本次按用户要求先发布现有 0.8.2.0，不将它描述为上述技能问题的最终修复。四行宏正常执行到末尾也会无提示结束，现有发送入口不提供技能施放成功回执，尚需区分“命令已派发”与“游戏实际执行”。

## 0.8.2.0：切职状态保护

- 识别数字 `/gs change N`、`/gearset change N`（普通半角空格或 Tab），目标套装存在且涉及跨职业时，跟踪此次转换。
- 首个后续 `/ac`、`/action` 前核对角色对象职业、玩家状态职业、热键栏职业及当前套装编号。尚未一致就保留当前行；一致后派发一次，不自动重试。
- 保护前的聊天、表情仍照常执行；技能延期时后续行依序顺延。显式 `<wait.N>` 从实际派发之后开始计算，不缩短等待、不集中补发。
- 从首次阻塞开始 10 秒硬截止；超时停止整段宏并报告状态。取消、登出、角色变化、新运行会清理旧跟踪。
- 不添加统一 3 秒或其他固定缓冲，不等待所有技能冷却，不通过 ActionManager 直接施法。
- 修复旧宏同步回调停止并启动新宏后抛错时，旧异常误停新宏的边界问题。

**这些状态一致并不能证明原生技能名缓存已经完成更新。** 日志中的 `[切职保护]` 记录只代表观察到的职业/套装状态，不能当作技能成功证明。命名套装、本地化别名、其他插件切职命令、特殊空格不在本次识别范围。

## 界面、原图与常用栏

- A 主界面搭配 B 编辑界面，便于分类、搜索及整理宏组和子宏。
- 独立常用宏悬浮栏，主窗口关闭也能直接运行收藏宏、宏组或单个子宏；支持添加、编辑、移出、拖动、锁定、收起及布局设置。
- 修复添加选择器不断拉长、窗口重复缩放及底部大块留白；标题旁单行显示“左键运行，右键编辑或删除”。右键移出常用栏只取消收藏，不删除宏正文。
- 图标使用用户提供的蓝发原图，没有重新生成或重绘。DLL 内嵌资源保留原始 PNG 字节；卫月列表图标仅等比缩小并透明留边为 512×512。安装清单和在线索引都指向本版图标。

## 原有功能与兼容性

默认额外行间隔为 **0**，每帧最多一行。保留宏组自动衔接、单独子宏运行、可选解除 15 行限制、每宏最多 64,000 字符、小数等待、倒计时触发和整段中止；没有统一音乐时间轴。

配置版本 **8**、导出格式 **4** 不变，已有宏与收藏无需重建。

- `/aklmacro`：主界面
- `/aklmacro bar`：常用宏栏
- `/aklmacro stop`：中止运行
