日期：2026-09-18。版本 `3.2.5.5`，Dalamud API 15。

- 核心测试 193 项通过。新增匹配优先级、别名、部分匹配、同名版本、接收顺序和较早点歌的补排检查。

- 合奏调度使用可控适配器验证延迟开奏、等待准备、超时及本曲结束后暂停。没有模拟出“全队已准备”的结果。
- 原生 ImGui 鼠标操作验证开始与暂停、搜索后加歌、多版本直接安排，以及旧节目单搜索弹窗回归。
- 1100x740、760x540 和 140% 字体缩放的真实界面渲染，截图位于 `verification/`。人工查看列表、弹窗和曲库，未使用网页或设计稿代替界面源码。

- 原 v0.5 的旧数据副本升级检查已通过；本次仅修改名称、署名、标题和发行元数据，保留内部标识及数据格式。

## 运行边界

本发行版的游戏内加载、实时观众聊天、实际乐器发声、同机多开与多设备连续合奏尚未验收。真实 Playback 测试不等同于游戏内合奏通过。

合奏复用 MidiBard 原有准备流程。多设备模式等待主控收到自己的切歌命令并完成载入，不重复载入同一曲；它不能证明远端文件相同。各端需预先准备同序播放列表、轨道、乐器及合奏监听。

队列拥有的 Playback 不再触发原播放列表循环或自动切歌，避免两套调度同时推进。显式停止中断当前记录，暂停不算完成，重试和重排保留历史。

发布包不包含个人 MIDI、配置、点歌记录或 Dalamud 开发库。安装前停用同名内部标识的原版或开发插件，并备份配置。

## 游戏内验收

1. 停用旧版，从在线仓库安装本版或启用独立开发目录中的 `MidiBard2.dll`，打开“自动点歌”。
2. 先用两首短 MIDI，在单人模式发送两条点歌，核对队列顺序、自动播放及自然结束记录。
3. 验证暂停、继续、下一首、停止，以及无匹配和同名多版本。
4. 配置同机或 PMD 合奏，先检查各端同序播放列表与轨道，再验证两首连续合奏和准备超时。
5. 重载后核对历史和待演队列；重载不会自行开奏。
