# 演出房间与队员查看（3.2.5.9）

一间房间支持一名队长、一名主持人和最多七名只读队员，主持人不占队员名额。主持人不需要加入演奏小队，也不需要本地 MIDI 曲库。队长电脑保存有效队列并执行单人或合奏播放，主持人和队员断线不会让队长停止演奏。队长和查看队员须升级本版，建议主持人一并升级。

| 角色 | 查看当前及待演顺序 | 调整队列及控制连播 | 接收观众聊天点歌 |
| --- | --- | --- | --- |
| 队长 | 可以 | 可以，执行演奏 | 选为接收端时可以 |
| 主持人 | 可以 | 可以，由队长执行 | 选为接收端时可以 |
| 队员查看 | 可以 | 不可以 | 不接收 |

## 队长电脑

1. 停用旧版开发插件，在卫月插件安装器更新至 `3.2.5.9` 后启用，打开 MidiBard 的“自动点歌”。自行构建时也可启用独立开发目录中的同版本插件。
2. 在“演出房间”选择“队长 / 演奏端”，本地端口默认 `28765`，点击“创建演出房间”。组队时须由小队队长的主控端创建。
3. 樱花启动器的 TCP 隧道指向 `127.0.0.1:28765`。已有隧道使用其他本地端口时，可把插件的监听端口改为相同数值。隧道必须运行在队长电脑；不需要另开 WebSocket 服务。
4. 在插件中填入樱花分配的节点域名或 IP，以及公网端口。域名框只填主机名，不带 `http://`、端口或路径。
5. 点击“主持人邀请”旁的复制图标，把完整邀请私下交给主持人。点击“队员查看邀请”旁的复制图标，将查看邀请交给普通队员。两种邀请权限不同，不要把主持人邀请当作队员邀请分发。不要将口令、樱花访问密钥或启动器配置发布到公开仓库。

队长电脑、FF14、插件与樱花启动器均须保持运行。插件只监听本机回环地址，无需把监听范围扩大到所有网卡，也无需自行放行公网入站端口。

## 主持人电脑

1. 在“演出房间”选择“主持人”，粘贴邀请口令，点击“加入演出房间”。不需要安装樱花启动器。
2. 显示“已连接队长”后，“曲库”和“点歌队列”显示队长端数据。主持人原曲库保留，离开房间后恢复显示。
3. 主持人和队长都能加歌、上下移动、取消排队、设为下一首、处理未匹配点歌，以及开始、暂停、继续、停止、跳过当前曲目。
4. “设为下一首”调整下一首待演曲目；立即换歌使用顶部跳过按钮。单人暂停暂停当前曲，合奏暂停让本曲结束后停下连播。

## 普通队员电脑

1. 启用本版插件，打开“自动点歌 → 演出房间”，选择“队员查看”。
2. 粘贴队长发来的“队员查看邀请”，点击“加入演出房间”。不需要樱花账号或启动器，也不需要另建隧道。
3. 连接后打开“演出列表”，查看当前曲目、下一首和待演顺序。主持人或队长加歌、排序、指定下一首或删除后，列表自动更新。
4. 原 MidiBard 的 MIDI、播放列表、轨道、乐器和合奏监听仍按原方式配置。房间只同步节目单及状态，不传 MIDI 文件，也不替代合奏控制。
5. 断线时保留上次同步的列表并明确提示重连；恢复后自动更新。关闭房间后需要队长重新创建并分发新邀请。

查看邀请使用独立密钥，服务端拒绝该角色的全部控制指令。队员本机自动队列须先停止，正常的 MidiBard 合奏跟随播放可继续；进入查看不会主动暂停或停止它。查看界面没有加歌、排序、删歌或连播按钮。查看角色由邀请码决定，不根据游戏队伍成员自动授予；持有查看邀请的人可加入，最多七名同时在线。

## 观众自动点歌

房间默认由主持人接收聊天点歌。队长点击“开始连播”，观众在主持人能收到的频道发送 `点歌 曲名`，即可在队长队列中按接收顺序等待演奏。队列空了仍会等新歌。

在“演出房间 → 聊天点歌接收端”可切换为队长接收；同一时间只由所选的一端接收，避免两人同时听到公开聊天造成重复入队。主持人未入队时收不到小队频道，观众应在主持人能看到的说话频道或向主持人发送悄悄话。两端不用处于同一网络，但聊天可见范围仍遵循游戏规则。

主持人断线期间，队长保留管理和演奏能力；可手动切换队长接收新的聊天点歌。未收到的聊天不会事后补采集。

## 连接与数据

- 使用 TLS 加密 TCP，主持人和队员共用一条樱花 TCP 隧道。邀请包含节点地址、角色、独立随机密钥及证书指纹；连接时固定验证指纹，不绕过证书校验。修改查看邀请中的角色字段不能获得主持人权限。
- 关闭房间、重载插件或重启游戏后，旧邀请失效，需要创建房间并重新分享。地址和邀请不自动写入账号或游戏配置。
- 断线自动重连原房间并更新列表。加歌、排序、切歌等控制指令不会自动重发；未确认的观众点歌保留最多两分钟，重连时按原操作 ID 去重。
- 双方同时修改时，较旧列表发出的操作会明确拒绝并刷新列表。需要核对后再点一次，不会自动覆盖新顺序。
- 每房间最多保留 4096 条远程操作去重记录，达到上限时重新创建房间。共享快照上限 8 MB；超过上限会关闭共享，不影响队长本地数据。
- 主持人接收歌曲名称、版本、人数组合、当前队列及相关点歌。队员仅接收当前节目单中进行中、待演条目及播放状态，不接收完整曲库、观众点歌记录或条目备注。所有角色均不接收 MIDI 文件、本地文件路径或完整演出档案。乐手端仍须按原 MidiBard 方式备齐 MIDI、播放列表、乐器和轨道。

## 排查连接

先检查队长房间已创建，樱花启动器显示隧道在线，本地端口和插件一致，公网域名与端口正确。确认邀请与选择的角色一致；已有七名队员时需等其他查看连接退出。如果启用了樱花 IP 访问认证，主持人和各队员还需按樱花页面完成访问认证。不要关闭插件的身份校验。
