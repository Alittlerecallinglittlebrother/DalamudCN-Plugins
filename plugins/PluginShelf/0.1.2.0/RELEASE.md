# PluginShelf 0.1.2.0

首次发布到 DalamudCN-Plugins 在线插件库。API 15 / .NET 10 / Windows x64。

- 以黑灰白的简洁布局替代大卡片：常驻小型快捷栏，展开后搜索完整收藏。
- 自动发现已安装插件；主界面和设置入口独立收藏；中文别名、排序、配置保存和异常提示。
- 从本地开发版升级保留原 `shelf.json`，但上线前必须先停用同名开发版。

安装包是已离线验证的 0.1.2.0 本地交付包，源码 ZIP 包含对应工程和测试。构建零警告/零错误，核心 30/30、后端 20/20、UI 52/52。截图仅为离线合成界面；**新版本尚未在游戏内加载验收**，不保证每个第三方插件均提供公开的打开入口。
