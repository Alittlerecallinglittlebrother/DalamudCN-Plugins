# PluginShelf 0.1.2.1

交互修复：收藏夹展开后，普通单击「收纳」或「+」即可关闭，无需长按左键再松开。此前悬浮面板会占据 ImGui 的 hovered-window 状态，使快捷栏第二次快速点击只切换焦点而未触发按钮。本版仅在鼠标于相同快捷栏按钮内按下并松开时切换，避免面板的“外部点击关闭”与按钮切换冲突；仍保留键盘激活。

保留全部 v0.1.2.0 的收藏、别名、设置和黑灰白界面，配置格式未升级。测试覆盖普通第二次单击、快速单击、从搜索框切回、两个按钮互相切换及拖动排序。Release 构建零警告、零错误；核心 30/30、后端 20/20、原生 UI 59/59 离线回归通过。**本补丁尚未在游戏内加载或验证实际手感。**

在线版刷新自定义仓库后更新；若有同名本地开发版，请先停用，避免重复加载。手动覆盖升级保留 `shelf.json`。
