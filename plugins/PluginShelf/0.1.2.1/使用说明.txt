插件收纳盒 / PluginShelf 0.1.2.1
==============================

目标
独立的 Dalamud / 卫月 API 15 插件。把已安装插件的公开界面入口收藏为常驻快捷栏。
这是入口收纳工具，不是插件安装器，也不把其他插件的界面嵌入自己的窗口。

0.1.2.1 单击关闭修复
- 解决展开收藏夹后，再次单击“收纳”或“+”不能立即收起的问题。
- 快速连续点击、从搜索框切回快捷栏均能一次单击关闭；收藏和旧配置保持不变。

0.1.2 极简视觉调整
- 去掉青绿/暖金强调色与装饰性徽章；改为黑灰半透明底、白灰文字、悬停浅灰反馈。
- 展开收藏夹与管理面板的收藏页改为轻量列表；每项显示名称和打开动作，无大卡片。
- 全部插件页压缩为易浏览的列表，保留主界面/设置分别收藏与命令绑定。
- 保留 0.1.1 的紧凑常驻栏、折叠收藏夹和全部现有配置；无需重建收藏。

0.1.1 界面更新
- 常驻条默认仅显示“收纳”+ 最多 3 个一键入口 + 余项数量，旧配置也直接切换到新布局。
- 点击“收纳”或余项数字展开可搜索的收藏夹；点击入口发送一次打开请求，点击外部或 Esc 收起。
- 右键“收纳”解锁移动与排序；解锁后拖动 :: 调整位置。全部收藏与布局设置仍在管理面板。
- 在布局设置中可将常驻入口数量设为 0～6；0 表示常驻仅一个展开按钮和余项按钮。
- 收藏、别名、动作、旧配置均保留，不自动改变游戏设置或开发插件加载位置。

功能
- 自动读取已安装插件，排除自身，同内部名称优先采用已加载实例。
- 主界面与设置入口分别收藏，无须填写指令。
- 收藏列表与常驻快捷栏，名称/内部名称/中文别名搜索。
- 右键修改别名、默认动作或移除；右键也可临时打开其他公开界面。
- 收藏列表拖动排序；快捷栏解锁后可排序，拖动 :: 移动整条栏。
- 横/竖布局、双字缩写、缩放、常驻入口数、战斗隐藏、位置找回。
- 服务器信息栏的“收纳盒”鼠标入口（若全局隐藏该栏，请从插件自身设置找回）。
- 高级手动命令绑定。只调用当前注册的插件命令，不把文本发送到聊天频道。
- 多个不同命令可分别收藏；保存不会执行任何命令。
- 独立配置，原子替换并保留上一份 .bak；损坏/未来版本/外部改动时停止覆盖。
- 暂时未加载、卸载或失去入口的插件保留收藏，显示不可用原因。

显示说明
常驻条使用文字快捷按钮，展开面板使用紧凑列表；不依赖下载第三方图标。
公开入口的实际行为由目标插件决定，可能是显示/隐藏切换。
界面显示“已发送打开请求”仅指派发完成，不表示已检测到目标窗口。
快捷栏采用 Dalamud ImGui 绘制，不修改游戏原生快捷栏。

本地加载（一次设置，之后可全程鼠标使用）
1. 将插件压缩包完整解压到一个固定目录；不要只复制 PluginShelf.dll。
   PluginShelf.Core.dll、PluginShelf.json 和 PluginShelf.deps.json 保持与其同目录。
2. 在 Dalamud 设置的 Experimental / 实验性页面，找到 Dev Plugin Locations / 开发插件加载位置，
   添加解压后的 PluginShelf.dll 完整路径，启用该条目并保存。
3. 在插件安装器的 Dev Tools / 开发工具 -> Installed Dev Plugins / 已安装开发插件中，
   扫描并启用“插件收纳盒”。可设置启动时加载。不同汉化版本的标签可能略有差异。
4. 首次加载会显示收纳面板：点“全部插件”，为常用插件收藏“主界面”或“设置”。
5. 完成后关闭管理面板：常驻按钮直接点击使用，其余入口点击“收纳”后在收藏夹内选择。
   从旧版更新时，先退出游戏或卸载旧开发插件，将新包所有文件覆盖原解压目录，再加载；无需删除 shelf.json。

可选找回命令（正常使用不需要记）：
  /pluginshelf       打开收纳面板
  /pshelf            同上
  /pluginshelf dock  显示快捷栏并打开面板
  /pluginshelf reset 将快捷栏移回屏幕内并显示

配置及回退
配置为当前 Dalamud 插件配置目录下 PluginShelf/shelf.json；上一份为 shelf.json.bak。
仅本插件操作此文件，不读写其他插件配置，不改 Dalamud 全局配置。
若提示配置只读：停用本插件，备份 shelf.json 和 .bak，检查日志并修复配置后再加载。
要退回原来的使用方式，停用“插件收纳盒”即可；其他插件不受影响。
本次制作没有注册开发加载位置、没有热加载到现有游戏，也没有发布网络仓库。

源码构建
需要 Windows x64、.NET SDK 10、匹配的 Dalamud API 15 开发依赖。
优先使用参数 -DalamudHome，其次 DALAMUD_HOME 环境变量；否则自动寻找国服/国际服 Hooks/dev。
在源码根目录执行（PowerShell 7）：
  .\build.ps1
  .\build.ps1 -Validate -UiTests
或指定实际 SDK：
  .\build.ps1 -DalamudHome '完整的 Hooks\dev 路径' -Validate -UiTests
代码不捆绑 Dalamud 或游戏 DLL；它们由用户的 Dalamud 安装提供。
UI 测试使用本机 cimgui 和 Windows 微软雅黑字体；测试截图使用合成插件目录，不是游戏截图。

工程
PluginShelf.Core         配置、搜索、排序、动作校验、单次派发及原子保存
PluginShelf              Dalamud 接入与生产 ImGui 界面
PluginShelf.Core.Tests   不依赖 Dalamud 的核心回归
PluginShelf.BackendTests 真实 SDK 接口 + 隔离模拟后端集成回归
PluginShelf.UiTests      直接绘制生产界面的原生 ImGui 鼠标/布局回归

本版本没有实现
安装/更新/启停其他插件、插件界面嵌入、云同步、分组、按场景切换、手柄导航、专用 IPC 适配。
自定义命令不自动推断归属，请仅绑定自己确认过的目标插件打开命令。
测试通过不等于游戏内已加载或所有第三方插件行为均验证；请按随附验收清单进行真实环境确认。
