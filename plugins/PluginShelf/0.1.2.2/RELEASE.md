# PluginShelf 0.1.2.2

修复管理窗口被右下角缩放手柄误拉大到接近全屏、界面出现大片空白的问题。管理窗口现在保持紧凑尺寸，禁用自由缩放但允许从标题栏移动；重载时将旧版记录的过大窗口尺寸恢复到合理范围，原来的窗口位置尽量保留。高 UI 缩放也设置了适当上限，小屏幕则自动适配可用区域。

沿用 0.1.2.1 的单击“收纳”或“+”即可收起收藏夹的修复；收藏、别名和配置格式均未改变。构建零错误、零警告；核心 30/30、后端 20/20、原生 UI 63/63 离线回归通过，包括拖动窗口标题栏、尝试拖动右下角和高 UI 缩放情形。**本补丁尚未在游戏内加载验证**；附图仅是离线合成界面，不是游戏截图。

在线版刷新自定义仓库更新；使用同名本地开发版时，先停用旧版，再完整解压覆盖原目录，保留 `shelf.json`。
