# PluginShelf 0.2.1.0

作者：**断水剑**。本版从在线库 0.1.2.3 升级，包含分组总控和后续修复。

## 更新
- 增加分组编辑、整组启用/停用、逐项结果、停止后续队列与自我停用保护。
- 收藏、收藏夹、分组成员、分组快捷面板均提供每个插件的独立启用勾选框；默认显示未启用插件，方便重新打开。
- 增加同名安装/开发副本选择，展示版本与 DLL 路径；保存后单项和整组使用同一份。
- 停用唯一运行副本后记住其身份，修复多个副本全停后无法重新启用；全部已停用时不再误报歧义。
- 防止同时加载另一个仍在运行的同名副本；过期选择不会默默改用另一份。
- 修复单个插件资料异常使整个目录刷新失败；无法确认的状态不再伪装成“插件未加载”。
- 保留已有收藏、别名、顺序、位置和分组，配置升级至 v3。

“已经启用，未重复加载”是正常跳过，不是失败。保存分组或副本选择本身不会启停任何插件。

## 使用与升级
刷新自定义插件库后更新。使用同名本地开发版的用户先停用开发版，再安装/启用在线版；不要同时运行两个收纳盒副本。保留 `shelf.json`，升级前额外备份用于回退旧版。

多个同名目标插件：点该行的 **副本 / 选择副本**，按版本和 DLL 路径选择需要的一份，点 **记住此副本**，再单独启用或整组启用。
