# 插件收纳盒（PluginShelf）

当前在线版本 **0.2.1.0**。作者：**断水剑**。Dalamud API 15 / .NET 10 / Windows x64。

**轻松收纳，一键直达。**

## 功能

- 收藏常用插件的主界面、设置或已确认的命令入口；支持中文别名、搜索、拖动排序与紧凑快捷栏。
- **单独开关**：收藏列表、收藏夹、分组成员与分组快捷面板右侧都有独立“启用”勾选框；常驻入口右键也可操作。
- **分组总控**：新建分组后可整组启用、整组停用；逐项显示结果，允许停止后续队列。
- **同名副本选择**：查看类型、版本、DLL 路径和编号，指定并记住需要控制的一份，避免关掉后无法重新开启。
- 目录读取逐项容错；读取失败显示“状态未知”，不将全部收藏误报为未加载。

点击名称是打开界面；右侧勾选框才是启用/停用插件本身。只操作明确选择的插件，不安装、更新或删除其他插件，也不删除它们的配置。

## 在线安装

在 DalamudCN 设置的「自定义插件仓库」添加下列地址；已经添加过的用户只需刷新插件列表：

```text
https://raw.githubusercontent.com/Alittlerecallinglittlebrother/DalamudCN-Plugins/main/repo.json
```

搜索 **插件收纳盒** 后安装或更新。如果目前使用同名本地开发版，请先停用开发版，再使用在线版，避免重复加载；在线更新不会替换开发目录的 DLL。保留原来的 `shelf.json`，升级前建议另外备份。

初次使用在「全部插件」收藏常用入口，或到「分组总控」建立分组。右键快捷栏的「收纳」可解锁并移动位置；可用 `/pluginshelf reset` 找回。

有多个同名副本时，点插件行的 **副本 / 选择副本**，按完整 DLL 路径选择一份，再点 **记住此副本**。保存只保存选择，不会启动插件；之后再勾选启用或使用整组开关。

## 验证与兼容边界

Release 构建零错误、零警告；核心 **48** 项、后端 **47** 项、原生 ImGui 界面 **101** 项离线检查通过。公开包与已测试包 SHA-256 一致，对应源码压缩包解压后可重新构建。预览使用合成插件目录，并非游戏截图。

**0.2.1.0 尚未在游戏内对真实插件启停完成验收。** API 15 没有公开的启停接口，本插件通过受限的内部接口适配调用卫月标准加载/卸载流程；卫月内部接口变化、安全模式、合集归属或角色过滤冲突时会停止操作并说明原因，不强行绕过。请先用不影响当前游戏操作的插件测试。

配置自动升级至 v3，并保留旧收藏与分组；旧版会拒绝覆盖 v3。如需回退，请使用升级前额外保存的配置备份。批量启停不会强杀当前插件的构造/释放过程，也不会在停止队列时回滚已完成的项目。
